# Algoritmos 🧮

Repositorio con las tareas y ejercicios de la materia de **Algoritmos**. Aquí voy subiendo las implementaciones que se van dejando durante el curso, organizadas por tema.

## Contenido

- **Merge Sort** — algoritmo de ordenamiento por divide y vencerás.
- **Hashing** — estructuras de datos basadas en tablas hash (funciones hash, manejo de colisiones, etc.).
- **Programación Dinámica** — problemas resueltos mediante memoización y tabulación.
- **Programación Ramificada y Acotada (Branch and Bound)** — algoritmos de optimización combinatoria.

## Estructura del repositorio

```
.
├── merge-sort/
├── hash/
├── programacion-dinamica/
└── ramificada-y-acotada/
```

Cada carpeta contiene el código fuente de los ejercicios correspondientes a ese tema, junto con cualquier archivo de prueba o documentación adicional.


Tareas realizadas como parte del curso de Algoritmos.

## Notas

Este repositorio tiene fines educativos y de aprendizaje personal.
